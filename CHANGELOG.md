# Changelog

## 1.0.0 (2026-11-03)

- First release for Cyberpunk 2077 2.5.
- Adds a Mods group to Controls > Key Bindings with every keyboard action that installed mods add through Input Loader.
- Keeps those keys in sync with Mod Settings key options.
- Optional label files for mod authors: `r6/config/modkeybinds/*.json`.
